# HCC Dataset

This directory contains the Hepatocellular Carcinoma (HCC) dataset used in this project.

## Directory Structure

- **raw/**: Original, unmodified dataset files
  - `hcc_dataset.csv`: Original HCC patient data from CHUC, Portugal

- **processed/**: Cleaned and preprocessed data ready for modeling
  - Generated after running preprocessing scripts

## Data Source

The dataset contains real clinical data from patients diagnosed with HCC at the Coimbra Hospital and University Center (CHUC) in Portugal.

## Data Privacy

This dataset contains anonymized patient information. Please handle responsibly and do not attempt to re-identify individuals.
